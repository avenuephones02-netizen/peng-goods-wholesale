# GitHub Pages setup

1. Create a GitHub repository, e.g. `peng-goods-wholesale`.
2. Upload these files to the repository root so `index.html` is at the root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub to publish the site and open the generated `github.io` address.

The app already contains the Supabase Project URL and Publishable Key.
Never upload a Supabase service-role/secret key.
